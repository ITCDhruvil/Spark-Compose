# 6. Progress reports with tables → charts & KPIs

## Problem statement

Project updates often live as static tables. Stakeholders need charts, KPI rows, and progress visuals inside the same report without switching to Excel or BI tools.

## What already exists

- Tables + Spark Chart (table → chart)
- Chart blocks, KPI widgets, progress analytics AI helpers
- Recharts / Chart.js in the editor

## How it should be done

1. Authors enter or paste tabular progress data.
2. Convert selected tables to chart/KPI blocks with one action.
3. Optionally use AI to suggest chart type or progress narrative.
4. Publish the combined narrative + visuals as a client update.

## Tweaks & new features

- Live data connectors (API → table refresh)
- Chart templates per report type (S-curve, earned value, manpower)
- Snapshot/export charts with the document

## Real-world outcomes

- Single-document progress packs for clients and PMs
- Reusable analytics-in-doc pattern beyond construction
