# 13. HSEQ / method statement / toolbox talk packs

## Problem statement

Safety and method documents must be complete, consistent, and easy to produce on site. Blank-page authoring leads to missed controls and weak toolbox talks.

## What already exists

- Construction-focused draft/ask prompts
- Callouts, checklists, headings, images
- Guided draft / playbook patterns
- Local construction terminology in spell-check

## How it should be done

1. Ship playbooks for method statements, RAMS, toolbox talks, ITPs.
2. Use callouts for hazards/PPE/hold points.
3. Run glossary + find-issues against company HSEQ standards.
4. Export PDF packs for site briefings.

## Tweaks & new features

- Hazard/PPE icon library (roadmap-aligned)
- Mandatory section gates for HSEQ docs
- Sign-off / acknowledgement mode for crews

## Real-world outcomes

- Faster, more consistent safety documentation
- Direct reuse of current construction domain strengths
