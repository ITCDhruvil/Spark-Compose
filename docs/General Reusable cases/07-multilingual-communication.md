# 7. Multilingual client & field communication

## Problem statement

Multinational projects need the same update, toolbox talk, or method summary in multiple languages without rewriting from scratch or losing structure.

## What already exists

- Translate submenu / API
- Tone rewrite for audience adaptation
- Summarize for shorter versions of the same content

## How it should be done

1. Author the master document in the source language.
2. Translate selection or whole sections via Spark AI.
3. Adjust tone for client vs crew audiences.
4. Store language variants as linked documents or sections in the host DMS.

## Tweaks & new features

- Side-by-side bilingual view
- Locked terminology glossary per language
- “Translate for site crew” / “Translate for client” presets

## Real-world outcomes

- Faster multilingual communication with consistent meaning
- Same translate pipeline for any industry host product
