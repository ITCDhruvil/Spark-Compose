# 10. Action items & meeting-to-document workflows

## Problem statement

Meetings and site walkdowns produce unstructured notes. Teams need structured minutes, owners, and follow-ups inside a durable document.

## What already exists

- Action-items AI API/feature
- Checklists / task lists in the editor
- Summarize and text-to-table tools
- Draft flows for structured sections

## How it should be done

1. Paste or dictate raw notes into the editor.
2. Run action-items extraction → task list with owners/dates where available.
3. Summarize decisions; convert tables of commitments as needed.
4. Sync tasks to host PM tools (Jira, Asana, etc.) via integration.

## Tweaks & new features

- Meeting template playbook
- Owner/date schema on task items
- Webhook export of action items

## Real-world outcomes

- Faster conversion of meetings into accountable follow-up docs
- Same pipeline for standups, toolbox talks, and client calls
