# Tone and rewrite

## What it is

**Preset tones** and **rewrite styles** applied to selected text — Professional, Casual, Simplify, Bullets, Fix grammar, etc.

## Problem it solves

Same facts need different voice for email vs executive summary vs site briefing.

## How to use

1. Select text.
2. Selection menu → **Tone** (or rewrite prompts).
3. Pick a preset, e.g.:
   - **Tones:** Professional, Casual, Formal, Executive, Technical, …
   - **Prompts:** Simplify, Concise, Clarify, Bullets, Active voice, …
4. Confirm result.

## Notes

- API: `/api/ai/custom-tone`
- Full list: `tone-options.ts` (`ALL_TONE_OPTIONS`)
- Custom tone string can be typed in submenu for one-off instructions.
