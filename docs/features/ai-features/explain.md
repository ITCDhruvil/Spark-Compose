# Explain

## What it is

Rewrites or explains selected text for a **specific audience** — plain language or tailored for site crew, client, or engineer.

## Problem it solves

Same technical content must be understood by different stakeholders on site and in the office.

## How to use

1. Select text.
2. Selection menu → **Explain** → choose:
   - **What does this mean?** — plain explanation
   - **For site crew** — field-friendly
   - **For client** — professional, non-jargon
   - **For engineer** — precise technical
3. Confirm or undo the result below selection.

## Notes

- API: `/api/ai/ask` or explain-specific routes via `use-in-editor-rewrite`
- Also available in Spark AI dropdown under Explain section.
