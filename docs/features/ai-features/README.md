# AI features (Spark AI)

**Spark AI** is the intelligent layer on top of the editor. Features call server-side APIs and (except local spelling) consume OpenAI tokens. Usage is tracked on the **Cost & Analysis** page.

## How to open Spark AI

| Entry point | When |
|-------------|------|
| **Toolbar → Spark AI** | Browse all features, toggles, upcoming roadmap |
| **Select text → bubble menu** | Improve, translate, summarize, etc. |
| **Table toolbar → Spark Chart** | Instant charts (no AI — see [smart Spark Chart](../smart-features/spark-chart.md)) |

## Common patterns

- **Select text first** for selection-based tools.
- **Confirm / Undo** — many AI edits show an action bar to keep or revert.
- **Toggle off** autocomplete, spelling, or grammar in Spark AI when you want zero interference.
