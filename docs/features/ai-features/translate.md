# Translate

## What it is

Translates **selected text** into another language while preserving meaning and tone where possible.

## Problem it solves

Multilingual sites and international clients need quick drafts in Spanish, French, German, etc., without leaving the editor.

## How to use

1. Select text.
2. Selection menu → **Translate** → pick language (English, Spanish, French, German, …).
3. Review translation below selection → Keep or Discard.

## Notes

- API: `/api/ai/translate`
- Languages: `translate-languages.ts` (searchable in menu)
- Not a certified legal translation — review before formal submission.
