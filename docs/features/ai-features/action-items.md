# Action items

## What it is

Extracts **tasks, follow-ups, and checklist items** from selected meeting notes or paragraphs.

## Problem it solves

Site meetings and calls produce narrative text; PMs need a task list without re-reading everything.

## How to use

1. Select notes (minutes, diary entry, email paste).
2. Selection menu → **Action items**.
3. Review generated checklist / tasks inserted below or in structured form.

## Notes

- API: `/api/ai/action-items`
- Best with clear obligations (“John to…”, “Action:”, dates, owners).
