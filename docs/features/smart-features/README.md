## When to use smart features vs Spark AI

| You want to… | Use |
|--------------|-----|
| Insert a 5×4 table | `/table5x4` or table toolbar |
| Paste Excel/CSV as table | Smart paste |
| Turn existing table into bar chart | **Spark Chart** (no AI) |
| Rewrite paragraph for client | Spark AI → Improve / Tone |
| Fix typo as you type | Spelling toggle (local) |
