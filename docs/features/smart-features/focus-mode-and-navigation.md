# Focus mode and navigation

## What it is

Tools to reduce distraction and move around the document quickly.

## Problem it solves

Writers need a clean canvas; reviewers need find/replace and jump-to-section.

## Features

| Feature | How |
|---------|-----|
| **Focus mode** | Toolbar → expands editor full-screen, hides outline chrome |
| **Find & replace** | Toolbar or command palette |
| **Keyboard shortcuts** | Shortcuts dialog from toolbar |
| **Status bar** | Word count, char count, hints for `/` and `Ctrl+Shift+P` |
| **Empty line hint** | `+` on empty lines for quick insert |

## Notes

- Focus mode state in `rich-editor.tsx`
- Find/replace: `find-replace-dialog.tsx`
