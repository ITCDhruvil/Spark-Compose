# What is Spark Compose?

Spark Compose is a **browser-based rich text editor** built for people who write construction and project documentation every day — site diaries, method statements, toolbox talks, client updates, and technical notes.

## What it is not

- Not a full document management system (yet)
- Not real-time multi-user collaboration (Yjs is in dependencies for future use)
- Not a replacement for Excel — but it can **chart table data** and embed KPI widgets

## What you can do today

### Write and format

- Headings, bold, lists, tables, images, callouts, checklists, code blocks, horizontal rules
- Font family, size, color, alignment, links, comments
- Document outline (table of contents sidebar)
- Focus mode for distraction-free writing

### Work faster (smart features)

- Type `/` for slash commands (`/table3x3`, `/h2`, `/callout warning`, etc.)
- Markdown-style line shortcuts (`# `, `- `, `1. `, `> `)
- Smart paste from Word, Markdown, CSV
- Drag blocks to reorder; floating toolbars on tables, images, and charts

### Use Spark AI

- Improve, summarize, translate, change tone
- Draft new content from a brief
- Ask questions inside the document
- Turn tables into charts, KPI rows, or progress analytics
- Local spell check + AI grammar suggestions

## Where it runs

Spark Compose is a **Next.js web app**. The main editor is at `/`. A separate **Cost & Analysis** page at `/cost` tracks AI usage.
