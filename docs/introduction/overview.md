# Overview

**Spark Compose** is a rich text editor aimed at construction and project teams. It combines:

1. **A full document editor** — headings, tables, images, callouts, lists, code, video embeds, and more.
2. **Smart authoring** — shortcuts and workflows that save time **without** calling AI.
3. **Spark AI** — writing help, structure suggestions, and analytics powered by large language models.

## Product name

| Name | Meaning |
|------|---------|
| **Spark Compose** | The editor product (home page title) |
| **Spark AI** | The AI feature layer (toolbar ribbon + selection menu) |
| **Spark Chart** | Instant chart-from-table (branded analytics entry point) |

## Core idea

> Make everyday editing fast first; add AI where it clearly saves time.

Users should be able to insert a `4×4` table, paste a site report, or fix a typo **without** opening an AI panel. AI is for improve, summarize, draft, gap analysis, KPI cards, and similar tasks that need language understanding.
