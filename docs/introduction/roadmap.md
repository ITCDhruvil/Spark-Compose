# Roadmap (coming soon)

Features listed here are **planned** but **not shipped** in the current editor. They appear in the product under **Spark AI → Upcoming** with a “Soon” badge.

This gives clients visibility into direction without over-promising current capability.

## Content generation

| Feature | Description |
|---------|-------------|
| Image generation | Site photos, diagrams, illustrations from text |
| Diagrams & flowcharts | Procedures → flowcharts and sequence diagrams |
| Before / after visuals | Progress comparison images |
| Icon & callout library | PPE icons, hazard callouts, hold-point markers |

## Construction authoring

| Feature | Description |
|---------|-------------|
| Method statement builder | Structured scope, plant, sequence, risks, controls |
| Toolbox talk & RAMS | Generate or standardize safety documents |
| Spec / clause validation | Check against specs, standards, brief, glossary |
| Drawing references | Link text to drawing numbers and revisions |
| Inspection & test plans (ITP) | Hold points, checklists, QA/QC blocks |

## Social & publishing

| Feature | Description |
|---------|-------------|
| Multi-platform export | LinkedIn, X, Instagram, email formats |
| Platform preview | Character limits, crops, layout per platform |
| Smart social tags | Hashtags, mentions, trade-specific keywords |
| Publishing assistant | Schedules and copy variants |
| Site update cards | Shareable cards for Teams / Slack / WhatsApp |

## Graphs & analytics (extended)

| Feature | Description |
|---------|-------------|
| Cost & usage insights | Embedded budget and resource summaries |
| Citations & sources | References, standards, evidence links |

## Collaboration & workflow

| Feature | Description |
|---------|-------------|
| Review modes | AI perspectives (client, engineer, PM, site, crew) |
| AI approval workflow | Comments, suggested edits, audit trail |
| Templates library | Daily reports, incidents, VOs, NCRs, handover |
| Project workspace | Multi-doc glossary, standards, shared assets |

## Media & multimodal

| Feature | Description |
|---------|-------------|
| Accurate dictation | Push-to-talk with construction vocabulary |
| Video generation | Site clips and explainers |
| Voice-to-document | Recordings → minutes and action items |
| PDF & drawing intelligence | OCR, tables, annotations from uploads |

## Knowledge (RAG)

| Feature | Description |
|---------|-------------|
| Hybrid project RAG | Vector + keyword search over project docs |
| Multimodal ingest | PDF, Excel, drawings, photos with citations |
